/api/github
Token · Cache · Guards

GITHUB

GraphQL + REST
Contribuições · Repositórios

RESILIÊNCIA

Cache CDN
Fallback curado

FalaA arquitetura é uma SPA com uma função serverless. O token do GitHub fica só no servidor; o navegador nunca recebe esse segredo.
