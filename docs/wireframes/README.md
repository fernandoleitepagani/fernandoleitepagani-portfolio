# Wireframes — Laboratório 01

Quatro wireframes de média fidelidade para as páginas principais do portfólio. Cada SVG contém a
prancha desktop e uma prévia mobile de 390 px, com anotações de responsividade.

## Importar para o Figma

1. Abra o Figma e crie um arquivo de design.
2. Arraste um arquivo `.svg` para a tela ou use **File → Place image**.
3. Selecione os elementos importados e use **Ungroup** para editar os componentes individualmente.
4. Salve o arquivo Figma no seu espaço de trabalho.

> Os SVGs são arquivos de intercâmbio vetorial importáveis; o formato nativo binário `.fig` é criado
> pelo Figma ao salvar o documento, não por geração de texto.
